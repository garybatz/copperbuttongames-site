# Copper Button Games V2.1 — cache-safe update

This version is functionally the same redesign as V2, but the CSS and JavaScript files
have new filenames (`retro-v2.css`, `retro-v2.js`) so browsers/GitHub Pages cannot reuse
the old V1 stylesheet from cache.

Replace your current site files with these, but KEEP your existing CNAME file.

Then commit and push. After GitHub Pages redeploys, refresh the site normally.
