# Copper Button Games — Website V2

This is the retro/16-bit refresh of the live Copper Button Games landing page.

## What changed
- Uses the copper D-pad emblem as the studio mark
- More overt retro-game / 16-bit visual language
- Modern typography remains readable
- Subtle scanlines, pixel grid, game-status labels and pixel UI
- Studio principles section
- Project teaser section
- Contact section
- Responsive mobile layout
- Tiny Konami-code easter egg: ↑ ↑ ↓ ↓ ← → ← → B A

## Updating your existing GitHub Pages repository
You do **not** need to change DNS, GitHub Pages settings, or the CNAME.

1. Unzip this package.
2. In your local `copperbuttongames-site` repository:
   - Replace `index.html`
   - Replace `styles.css`
   - Add `script.js`
   - Add the `assets` folder containing `copper-button-emblem.png`
3. Keep your existing `CNAME` file exactly as it is: `copperbuttongames.com`
4. GitHub Desktop should show the changed/new files.
5. Commit with a message such as `Retro website redesign`.
6. Push to `main`.
7. GitHub Pages will redeploy automatically.

No VentraIP changes are required for this redesign.
